# 변경 기록

## 1.2.1 · 2026-11-10

- 공용 메뉴를 `Tools > Skeletal Mesh Cutter` 하나로 통합하고 공용 창 제목을 맞춥니다.
- 기존 `MeshTools/Skinned Mesh Cutter`, `MeshTools/Model Mesh Cutter` 메뉴를 제거합니다.
- 기존 `SkinnedMeshCutterLauncher.Open`, `WindowFactory`, `OpenModelCutter` API와 프리셋 형식은 유지합니다.
- 테스트와 검증 코드를 배포 UPM 경로 밖의 `Development/Tests`로 이동합니다. 설치 패키지에는 툴 코드만 포함합니다.

## 1.2.0 · 2026-11-10

- 공용 Model Mesh Cutter 창에 모델 루트와 하위 메시 전체·개별 선택을 추가합니다.
- 메시별 독립 마스크 편집과 공용 프리셋 저장을 지원합니다.
- 선택한 메시를 같은 평면으로 각각 절단하고 원본 이름, 계층, 재질과 본 연결을 보존합니다.
- 콜라이더 내부·선 클릭, 개별 포함·제외, 모두 포함·제외를 지원합니다. 제외는 PART 출력에 적용합니다.
- 여러 메시의 표면과 본을 함께 사용해 출력 래그돌을 구성합니다.
- 물리 콜라이더가 모두 제외된 본의 Rigidbody와 해당 강체에 연결되는 Joint를 정리합니다.
- 기존 단일 메시 창 확장 API와 프리셋 읽기를 지원합니다.
- 프로젝트 전용 편집 창에서 재사용할 다중 메시 절단, 마스크 세션, 콜라이더 선택 및 빈 Rigidbody·Joint 정리 API를 공개합니다.
- 저장소와 패키지에 MIT License를 추가합니다.

## 1.1.1

- 래그돌 자동 생성기를 프로젝트의 설치 환경에 따라 선택합니다.
- 별도로 설치한 Bz가 있으면 사용하고, 없으면 Unity 내장 Ragdoll Builder로 자동 생성합니다.
- Unity 2022.3 위저드 및 Unity 6 일반 객체 형태의 내장 생성기를 각각 지원합니다.
- 실제로 비스듬하게 잘린 BoxCollider만 Convex 메시로 잘라 골반·가슴 콜라이더 돌출을 수정합니다.
- 잘리지 않은 레퍼런스와 축에 맞는 BoxCollider는 기존 종류를 보존합니다.
- 기존 생성 출력과 게임 프로젝트의 패키지 참조는 자동으로 변경하지 않습니다.

## 1.1.0

- Unity 2022.3 및 Unity 6 API 호환 분기와 ProBuilder 5/6 공통 의존성.
- 원본 파츠별 열린 단면 닫기, 공면 절단 허용, 캡 UV와 스킨 가중치 보존.
- 래그돌 레퍼런스 보존, 실제로 잘린 구·캡슐만 Convex 메시로 변환.
- 포즈·표시 캐시와 공간 검색을 통한 마스크 편집 최적화.
- 사각 선택에서 연결된 메시 전체 및 가려진 표면 포함 지원.
- 프로젝트 모델에 의존하지 않는 공용 회귀 테스트.
