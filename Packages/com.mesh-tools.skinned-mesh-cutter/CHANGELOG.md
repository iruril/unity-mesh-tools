# 변경 기록

## 1.1.1

- 래그돌 자동 생성기를 프로젝트의 설치 환경에 따라 선택합니다.
- 별도로 설치한 Bz가 있으면 사용하고, 없으면 Unity 내장 Ragdoll Builder로 자동 생성합니다.
- Unity 2022.3 위저드 및 Unity 6 일반 객체 형태의 내장 생성기를 각각 지원합니다.
- 실제로 비스듬하게 잘린 BoxCollider만 Convex 메시로 잘라 골반·가슴 콜라이더 돌출을 수정합니다.
- 잘리지 않은 레퍼런스와 축에 맞는 BoxCollider는 기존 종류를 보존합니다.
- 기존 생성 출력과 게임 프로젝트의 패키지 참조는 자동으로 변경하지 않습니다.

## 1.1.0

- Unity 2022.3 및 Unity 6 API 호환 분기와 ProBuilder 5/6 공통 의존성.
- 원본 파츠별 열린 단면 닫기, 공면 절단 허용, 캡 UV와 스킨 가중치 보존.
- 래그돌 레퍼런스 보존, 실제로 잘린 구·캡슐만 Convex 메시로 변환.
- 포즈·표시 캐시와 공간 검색을 통한 마스크 편집 최적화.
- 사각 선택에서 연결된 메시 전체 및 가려진 표면 포함 지원.
- 프로젝트 모델에 의존하지 않는 공용 회귀 테스트.
